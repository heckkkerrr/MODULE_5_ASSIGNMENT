## Description
This repository contains simple Java answers and practical programs for the supplied Module 5 assignment.

## Topics
Java annotations, reflection, Maven lifecycle, dependencies, plugins, and small Maven practical exercises.

## Structure
- `Assignment_Answers.md` contains concise answers and the question-to-file map.
- `src/` contains small runnable Java examples.
- `pom.xml` is included where Maven is required.

## Prerequisites
Java 17 or later. Module 5 practical Maven examples also require Maven.

## Compile and run
From `src`, compile with `javac *.java` and run a class with `java ClassName`. Some examples create files in the current directory. Intentional deadlock examples are labelled and should only be run for a short demonstration.

## Question-to-file mapping
- Java Annotations: src/AnnotationExamples.java
- Creating Custom Annotations: src/AnnotationExamples.java
- Maven Framework: pom.xml
- Repositories, Dependencies: pom.xml
- Practical Exercise Suggestions: pom.xml and src/AnnotationExamples.java
